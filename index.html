—

Один и тот же автомобиль (по VIN): 1-й круг — «не продано», один из следующих кругов — продано дороже стартовой цены именно этого 1-го круга. Избранное — лоты, которые вы отметили звёздочкой

—

Отметить лот можно звёздочкой в последней колонке на вкладке «Уведомления Telegram»; снять — нажатием на звёздочку здесь или там (если по лоту есть галочки или комментарий, сайт спросит подтверждение — они удалятся вместе со звёздочкой). В последней колонке — чек-лист (залог, ИП, запреты, НДС, ключи, документы) и комментарий. Отметки, галочки и комментарии хранятся в этом браузере на этом устройстве (на другом устройстве или после очистки данных сайта они не появятся).

Источник — официальный API torgi.gov.ru, категория «Автомобили и мототехника». Базовый сбор 12–13.09.2026, расширенный бэкафилл по торговым площадкам — 15.09.2026 (обход лимита API в 10 000 записей на статус через фильтр по площадке, отдельно для каждой из 8). Годы выпуска распознаны из текста лота регулярным выражением и найдены не у всех записей. «Круг торгов» — счётчик по VIN среди собранных данных, непрерывных с января 2022 года; для лотов, впервые выставленных ещё раньше, круг теоретически может быть занижен, но таких в базе практически нет. Единичные точечные пропуски возможны из-за нестабильности сайта во время долгого обхода — не системный сдвиг, просто отдельные лоты. «Цена vs медиана модели» — стартовая цена лота против медианы реальных цен сделки по той же марке и модели (не меньше 3 сопоставимых продаж, иначе не показываем); считается по всей базе целиком, независимо от текущих фильтров. Значения ниже 10% от медианы отмечены как аномалия — это почти всегда доля в праве собственности или похожая особенность лота, а не настоящая скидка.
